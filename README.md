## Публикация на GitHub Pages
1. Создайте репозиторий, залейте содержимое этого архива в корень (index.html, CNAME, .nojekyll).
2. Settings → Pages → Source: Deploy from a branch → main / (root).
3. Для домена binaryview.io: у регистратора добавьте A-записи на 185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153 (и CNAME www → <user>.github.io), затем включите Enforce HTTPS.
